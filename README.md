# VNDPrime Studio — Portfolio Site

A clean, fast one‑page portfolio for a boutique design & web studio. 
No frameworks; just HTML/CSS/JS so you can host anywhere.

## Files
- `index.html` — landing page
- `case-study.html` — template for case studies
- `styles.css` — responsive styles
- `script.js` — small JS for mobile nav & year
- `assets/` — SVG placeholders (logo, favicon, mockups)

## Customize
- Search for `VNDPrime` and replace with your studio name if needed.
- Replace SVGs in `assets/` with your own images.
- Update contact email in the form action (`mailto:hello@vndprime.example`).

## Deploy

### GitHub Pages (free)
1. Create a repo named `vndprime-site`.
2. Upload all files from this folder.
3. In repo settings → **Pages** → Branch: `main` → `/ (root)` → Save.
4. Your site will be live at `https://<username>.github.io/vndprime-site/`.

### Netlify (free)
1. Drag & drop this folder into https://app.netlify.com/drop
2. Done. You get a live URL like `https://vndprime-site.netlify.app`.

### Custom domain
- Point your domain’s A/CNAME to your host (Netlify/Pages) and set the site URL in the host’s dashboard.
